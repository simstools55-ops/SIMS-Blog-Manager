# SIMS-Blog-Manager v5.13.1

v5.13.0の改善後モニタリング・ライフサイクルを整理するPATCHです。

## 今回の修正

- 「改善の推移」は、各記事の**最新の有効なモニタリングサイクルだけ**を表示
- 観察終了後にDoctor再診→再改善→新モニターが開始された場合、旧モニター行を通常一覧から非表示
- Doctorが `WAIT / MONITOR` を返して追加経過観察を開始した場合も、旧サイクルを非表示
- 改善効果ありで卒業した案件と同様、終了済み旧サイクルは現役一覧から外す
- 旧サイクルのデータは削除せず、`改善履歴` と `Treatment_Performance` に保持
- 次の処置がまだ始まっていない「見直し候補 / 再診待ち」は、処置漏れ防止のため表示を継続

## 表示ルール

- 観察期間中 → 表示
- 観察終了・要再診、まだ未処置 → 表示
- Doctor再診後に新しい観察サイクル開始 → **旧サイクル非表示 / 新サイクル表示**
- Writer等で再改善し新しい観察サイクル開始 → **旧サイクル非表示 / 新サイクル表示**
- 改善完了 → 非表示（履歴保存）

- `appsscript.json`：変更なし
